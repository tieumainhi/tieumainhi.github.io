TeleBot privacy policy

Last updated: 2026-10-09

TeleBot is a private Telegram bot run by one YouTube creator (the "owner") on the owner's own computer. It is not offered to the public: only Telegram chats on the owner's allow-list can use it. TeleBot uses YouTube API Services. By using TeleBot you agree to this policy, to the YouTube Terms of Service and to the Google Privacy Policy.

What data TeleBot accesses

  • Public YouTube data through the YouTube Data API v3 with an API key: video and channel metadata and statistics (titles, tags, categories, durations, view/like/comment counts, subscriber counts), search results, most-popular charts and video categories. Top public comments of a few popular videos are read to find topics viewers ask for; comment text is not stored.
  • The owner's own channel data through YouTube Analytics with the owner's OAuth consent (read-only scopes youtube.readonly, yt-analytics.readonly, yt-analytics-monetary.readonly): daily views, watch time, average view duration, subscribers gained, views and estimated revenue by country, and search terms that led viewers to the owner's videos.

How the data is used

Only to produce private research reports for the owner in Telegram: trending videos and niches, keyword ideas, and the performance of the owner's own videos. TeleBot does not show ads, does not sell data and does not build profiles of YouTube users.

Sharing

To write summaries, TeleBot sends public video titles, tags, short excerpts and the public comments mentioned above, plus aggregated numbers from the owner's analytics for the owner's monthly report, to a large-language-model API (OpenRouter, privacy policy). Reports are delivered to the owner's chats through Telegram (privacy policy). No other data is shared with third parties.

Storage and retention

  • Data is stored in a local database on the owner's computer.
  • Public YouTube API data is deleted or refreshed within 30 days. A daily job removes older records; only derived scores (for example a 0–1 opportunity score) are kept longer.
  • The owner's analytics data is kept while the owner's authorization is active.

Revoking access and deletion

  • The owner can revoke TeleBot's access at Google Account permissions. TeleBot detects the revocation at its next daily run and deletes the stored analytics data 7 days later.
  • Running python -m telebot auth youtube --revoke revokes the token and deletes the stored analytics data immediately.
